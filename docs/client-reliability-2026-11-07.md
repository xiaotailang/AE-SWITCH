# 客户端可靠性继续开发

本轮从已发布预发布 `v0.1.0-core-features.1` 继续。上一轮最后一次完整测试的首次验证为 6/8、独立复测为 5/8，核心原生功能通过，进程和测试目录清理通过；这些记录不等于本轮重新验收。

本轮新增验证文件失败分类：缺少目标文件、换行不符、额外 UTF-8 BOM 与其他内容差异分别记录。诊断仅含固定状态标签、实际及预期字节数，不返回文件原文、路径、验证标记、命令或凭据。精确文件内容、成功的独立写入和读取、读取结果中的标记、最终回复、进程成功及临时文件清理仍须全部通过；诊断分类不改变通过门槛。

ZCode 和 WorkBuddy 的探针改为提供精确绝对文件路径，以及符合各自官方 Write 接口的 JSON 参数，消除相对路径、转义及换行含义的歧义。JSON 仅作为官方工具的调用说明，不写入验证文件；后续仍须独立 Read。这个输入修订的本地检查不代表真实模型一定遵循说明，最终成功需要新的真实客户端结果证明。

新端点和密钥须由明确指定的新私有输入提供。本轮只读检查发现项目旧测试文件及本机 Codex 当前所选连接与上一轮相同，尚未用它们发起新的远程测试。待更新后的输入确认后，以全新 G 盘 owner、当前构建及 `gpt-6.1-sol / xhigh` 隔离客户端连接重新查询模型并进行真实工具验证，不沿用旧凭据，不自动替换模型或强度。本机 Codex 配置、认证和当前会话不由测试修改。

本轮生成的程序、缓存、测试输入、浏览器 profile 和证据均在当前 G 盘项目内。完整验收及发布状态以本轮最终收据为准，当前不标记 `fullAcceptancePassed` 或 `publicReady`。

本地验证：314 项前端测试、454 项 core 库测试及 4 项 CLI 测试、468 项 desktop 库测试及 4 项 CLI 测试通过，3 项忽略测试不计入通过。最终验证器 67 项定向测试、TypeScript、rustfmt、Clippy 和教程一致性通过。实际编译 core 的八客户端配置集成、漂移拒绝、HTTP 活动与配置安全回归通过。生产 dist 浏览器 10 个场景及 10 份主题/尺寸截图检查通过，无横向溢出或新增区域 Axe 违规；该浏览器路径使用合成 IPC，不是真实官方客户端验收。

首次浏览器回归在切换客户端后过早访问仍在重置的模型筛选区域而超时。原始失败收据保留；脚本增加切换标题和折叠重置就绪等待后，以同一生产 dist 重跑通过。验收脚本修订不改变产品的默认折叠行为。
