# 常用流程精简与接入验证

本轮按日常接入的优先级整理已引入的四项能力。配置保护与安全断开保留在客户端主页面；请求活动默认收起。模型搜索和默认模型选择直接可用，收藏及最近使用放到默认收起的“常用模型”。具名多客户端方案保留底层事务和恢复保护，入口移到默认收起的“高级功能”，需要时再展开“配置方案”。关闭常用模型后主列表恢复全部可用候选，当前选择和搜索草稿保留。

本轮不新增客户端、自动路由、后台推理或插件运行时。所有可控构建、缓存、浏览器、客户端测试 profile 与证据均位于当前 G: 工作区。本机 Codex 配置与认证文件只读，测试前后核对哈希；`gpt-6.1-sol / xhigh` 是用户授权的 AE 隔离接入配置，不改变本机 Codex 或当前会话选择。测试密钥不写入公开源码、包、截图和原始日志。

真实文件验证仍要求同时观察关联的写入、独立读取、读取结果标记、助手结果及精确磁盘字节。本轮针对 Windows Codex 明确建议独立 `Get-Content -LiteralPath -Raw` 或 `ReadAllText()`；Hermes 明确精确写入、无换行或 BOM。显式失败退出与非终态输出不能充当读取成功。没有放宽精确文件检查，也不把历史失败重新判成通过。
