# GPT 长上下文与 80% 压缩设置

当前四步连接页按实际“端点＋所选模型”的声明管理上下文，压缩比例默认 80%。仅在确认该组合有长上下文加价档位，且模型最大窗口高于加价阈值时，“长上下文”开关才可用，默认关闭；主动开启并确认连接后才使用加价档位。这个开关调整客户端预算与网关限额，不修改供应商价格。不能按 GPT 系列名称统一套用 272K 或 1M。

确认有加价档位时，关闭状态的窗口不超过端点声明的加价阈值与实际模型最大窗口两者的较低值。例如某端点为精确模型声明 272,000 的阈值和 1,050,000 的最大窗口，则默认压缩阈值是 217,600；主动开启后为 840,000。若该端点实际声明 64,000／400,000，则使用这组值，不套用上述示例。界面允许 1–95% 的显式压缩比例调整。

只有实际连接 OpenAI 官方 HTTPS API `https://api.openai.com/v1` 时，才使用已核对精确模型的官方计费资料，包括 [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) 和 [GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4)。它们的公开长输入计费规则不授权第三方端点的同名模型，也不代表订阅场景。域名相似、其他端口或代理路径不能触发官方规则。

第三方端点由真实模型查询的对应条目提供明确档位。例如：

```json
{
  "id": "internal-gpt-alias",
  "context_window": 400000,
  "context_policy": {
    "standard_context_window": 64000,
    "long_context_window": 400000,
    "input_multiplier": 2,
    "output_multiplier": 1.5
  }
}
```

这里的 `context_policy` 是显式能力扩展，不是所有 OpenAI 兼容接口都提供的标准字段。仅返回模型 ID 或一个最大窗口时，无法推断计费档位，开关禁用，界面标示“计费阈值未确认”；GPT 未知能力采用最多 128K 的保守预算，不能把这个预算称为已验证的不加价额度。档位存在但倍率未知时同样不开放，除非端点明确声明 `surcharge: true`。倍率大于 1 表示确认有加价；端点明确 `surcharge: false`，或输入和输出倍率均为 1，表示没有长上下文加价，此时使用其真实最大窗口，无需开启加价档位。矛盾声明会拒绝。

模型查询完成后，应用在本地绑定实际端点、模型、认证方式和凭据范围；绑定不采信端点传入的同名字段。改变任一项后必须重新查询，旧声明不能直接保存到新连接，原始密钥不会写入绑定字段。已应用的第三方加价选择也绑定该查询范围；更换连接后，旧长窗口授权会拒绝转发，须重新确认。旧候选包没有这些绑定的计费声明需要重新查询。

每个客户端保存自己的应用快照，包括模型、长上下文是否开启、窗口、压缩阈值和比例；修改共享供应商不会替另一客户端开启长上下文。具名方案也保存这些非秘密元数据，预览标示上下文设置，应用时与原文件和选择记录一同进入原有事务、漂移检查及恢复流程。取消未保存的草稿不写入，确认后重载相应客户端。

关闭开关只限制后续上下文，不撤回已产生的费用。模型/端点若按整个会话计费，已经进入长档位的旧会话可能需要在关闭并重载后新建会话，不能通过本地开关改写上游历史账单。

AE 网关在转发文本生成、Chat、Messages 和压缩请求前校验已应用快照。长上下文关闭时，超出保守大小限额、模型不匹配、包含无法还原的上游保存历史或不能可靠计算的附件会被拒绝，而不是静默接受超出关闭档位的请求。关闭档位的文本限额以请求字节加输出/包装预留进行保守判断，可能早于客户端 Token 上限；它不是端点 tokenizer，不暗中删除消息、截断工具调用或自动更换模型。图片/文件路径在关闭档位下会明确拒绝，需要后续端点计数支持；这项限制在界面可见。用户主动开启后由客户端 tokenizer 与上游执行长窗口限制，不以字节数把 1M Token 错误缩减成约 250K 英文 Token，收费仍按上游规则执行。

思考等级的真实生效范围：显式等级随实际模型请求写入 Responses 的 `reasoning.effort` 或 Chat 的 `reasoning_effort`，协议转换和回退维持这一选择。默认值保留客户端原参数；缺少能力元数据时提供的是兼容选项。已完成的 `gpt-6.1-sol / xhigh` 真实生成只能证明端点接受并完成该请求，不能从客户端证明供应商内部算力或推理 Token 数。
