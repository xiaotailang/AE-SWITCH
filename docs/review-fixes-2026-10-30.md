# 提交前审查问题修复

本轮修复依据 `precommit-review-8e43dbbb89f94ba0b6d2e65a1c39dc94` 中的合成反例。原始失败证据保留，不回写为通过。

- Windows 私有目录使用当前进程令牌的用户 SID 替换 DACL，核验受保护状态及唯一允许项；不依赖 `USERNAME`。打开已有数据库和恢复记录前，对确切私有文件重新加固，覆盖 Windows 大小写别名及中断事务的 `.json.pending` 文件，防止文件自己的显式读取授权保留。仅处理 AE 数据目录，不修改上级目录或客户端原生目录 ACL。
- Windows 原生文件写入携带原快照，在排他文件句柄内完成内容校验、写入、刷新和回读；其他进程的写、删除与原子替换均不能穿过该阶段。新文件使用只创建新文件的语义，删除绑定同一受保护句柄。原生更新依赖持久化事务备份进行失败恢复；不在释放句柄后重开路径进行替换。文件正被客户端占用或快照不匹配时停止，用户应关闭客户端并重新预览。
- 安全断开只清理 AE 受管字段中确实新增的祖先对象；用户后来创建的空对象、空表和数组成员保留，TOML 的合法空表不再因全局清理导致渲染不一致。
- 工具验证使用有意收窄的标准读取语法和目标路径参数。回显、注释、引号中的读取关键词、无关参数或错误路径不能充当独立读取。支持的标准读取仍须关联成功结果、精确验证文件和助手回复；未识别的命令保持未验证，不按关键字猜测。
- 开发工作树保持原状。拟提交源码在正确仓库的 G 盘独立目录准备，保留根许可证，补齐运行时私有文件的忽略规则。未经本轮明确发布操作，不上传或推送。

所有可控测试、缓存、私有输入和证据在 G 盘。本机 Codex 的配置和认证只读，当前会话模型与强度不调整。`gpt-6.1-sol / xhigh` 仅用于用户授权的 AE 隔离客户端接入。Windows 文件保护的实测不代表其他系统具备同样的共享访问规则；跨平台原生验收另行记录。

最终检查与端到端结果以 `artifacts/acceptance/review-fixes-20261030/` 的本轮收据为准。测试通过不保证未知缺陷不存在；真实上游、客户端工具和完整系统验收分别报告。

验收工具也完成了三项修订：独立解析器测试接受明确指定且路径受检的当前官方安装清单；二进制隐私扫描使用保留块边界的字节匹配，并覆盖 UTF-8/UTF-16 跨块及重叠匹配；清理程序对保留句柄已经退出的同一创建身份快照，以及尚未取得停止授权的迟生 WebView 子进程，只观察自然退出。PID 复用、缺少身份、仍存活的保留进程继续拒绝；观察本身不授予结束其他进程的权限。清理失败时仍保存完整句柄清单供后续核实。

公开源码与包排除配置私钥、所有权记录、事务备份、客户端选择和网关配置。独立提交目录保留远端根许可证的原始字节；该许可证与应用许可证仅换行形式不同，例外单独记账，不覆写远端许可证。完整正式验收仍须以同一候选的原生结果与真实上游结果为准，不能把多轮局部成功拼成一次全部通过。
