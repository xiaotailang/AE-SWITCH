## 1. 用户真正要交付的产品

Windows 优先的 AE Switch 便携端点配置工具，完整解压后启动；连接用户已安装的八个官方客户端，以“输入端点 → 输入 API Key → 真实查询并选择模型 → 确认连接”为主流程。原生客户端、账户和历史继续在原位置使用，AE 合并连接必需字段。自动发现优先，多候选明确选择；发现不到时只补充一个安装目录，其余路径由程序识别。

不是要求再创建一个推理 Agent 或完整订阅平台。用户在 10 月 12 日明确要求聚焦目标、不做过度设计；在 10 月 19 日明确纠正了“无能力清单就不能设置思考程度”的错误结论。最终要求是未知清单仍可显式选择兼容等级，有明确清单时遵守清单，默认保留客户端选择。

持续有效的边界：

- 本机可控安装、测试、缓存和临时数据位于项目的 G 盘目录，及时清理自己的中间文件；不创建虚拟机。
- 保留大量既有源码改动，不修改原 C 盘客户端配置、不停止无关客户端、不接触原业务历史。
- 产品可放在任意可写本地目录，G 盘仅是本机测试边界，不把盘符限制写进产品行为。
- 真实查询、保存、配置与工具文件写读必须分别有证据，不能用模拟服务或 API 连通冒充官方客户端验收。
- 密钥、私有端点、实际开发路径及使用过的数据不能进入公开源码/便携发行包；隐私检查要说明覆盖范围。
