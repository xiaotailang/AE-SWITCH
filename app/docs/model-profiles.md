# 模型常用列表与具名配置方案

Agent Hub 的模型选择保留真实查询门槛。搜索只筛选当前连接已返回且已启用的模型，不构造额外模型 ID；收藏、最近使用按客户端 ID 与已保存连接 ID 隔离。未保存的连接可以搜索，不持久化其端点或密钥。只有确认连接成功或方案完整应用成功后才记录最近使用，取消和失败不会记录。

模型搜索和默认模型始终直接显示；收藏、最近使用筛选和星标放在默认收起的“常用模型”中。收起时显示全部可用模型并保留搜索及当前选择，再展开时恢复之前的筛选。多客户端方案位于默认收起的“高级功能 → 配置方案”，请求活动也默认收起；配置保护与安全断开仍可直接展开。

“具名配置方案”保存一组已确认的客户端连接选择。每项只有客户端 ID、供应商 ID、模型与可选思考等级；方案不包含 API Key、端点、原生用户目录、账号或历史。可以选择包含哪些已配置客户端，命名保存，预览后应用，用当前配置更新已有方案，或删除方案。被方案引用的供应商受到删除保护。

方案应用始终解析各客户端当前已确认的原生 profile；不会把保存时的用户目录搬到另一台电脑。预览列出客户端、前后连接与模型、思考等级，以及当前原生/便携目标类型。目标的精确路径继续由客户端位置设置管理。预览指纹绑定方案修订、供应商内容、网关与当前选择/配置快照；预览后任何相关变化都会要求重新预览。

应用先完成全部客户端的配置与字段所有权计划，之后将完整批量恢复日志持久保存在 AE 本地数据目录，再逐文件写入并回读，最后更新客户端选择。Windows 既有原生文件在排他句柄内核对快照、写入和回读；新文件只允许新建，删除绑定同一受保护句柄，冲突占用时停止。私有文件沿用原子写入器。失败时尝试恢复整组原始字节（包括环境配置与字段所有权），重启后也会先处理未完成的批量事务。恢复前逐个检查当前内容；如果客户端在过程中另行编辑，AE 保留该外部编辑和恢复备份，停止覆盖并报告需要恢复。外部编辑与文件锁可能使自动回滚无法完成，因此界面不会把此类失败显示为成功。

本地恢复日志为安全恢复暂存完整配置字节，可能含原生配置中的敏感字段；它不进入方案摘要或 IPC 预览，成功或完整回滚后删除。恢复日志与配置所有权记录使用独立本地私钥认证完整性，防止损坏或被修改的恢复内容写回客户端。私钥 `runtime-integrity.key` 保存在 AE 数据目录中，禁止随发布包携带；已有记录但私钥缺失时会停止恢复，不静默生成新私钥。认证不加密本地配置，也不防护已能读取该用户所有私有文件的进程。请勿分享已使用的 `data/` 目录。开发测试使用项目 G 盘中的隔离配置、缓存与临时目录；产品仍支持任意可写本地目录。

这些操作管理连接配置和新任务的模型选择。它们不发起推理、不切换当前 Codex 会话模型、不修改后台模型任务，也不把配置回读通过视为真实上游或工具写读验收通过。客户端是否即时加载配置、已有会话保留模型等行为由客户端决定，应用后按提示重新加载。
