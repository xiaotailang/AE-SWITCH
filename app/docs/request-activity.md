# 请求活动

连接页下方展开“请求活动”，查看当前客户端经过 AE 本地网关的最近请求。记录总量在所有客户端间共享，最多 200 条，较早记录自动淘汰；网关重启后清空。折叠时页面停止轮询，展开后每 3 秒刷新。清空只移除当前客户端的内存记录，不中断正在运行的任务；已清空的进行中请求结束后不会重新出现。

记录包含请求模型、入口接口、上游协议类别、流式请求标记、HTTP 状态、生命周期、总耗时、首包耗时、返回字节数及上游响应报告的 token 用量。模型是请求中的已配置名称，不是对中转商实际运行模型的证明。首包指 AE 向客户端交付的第一个非空响应数据块，可能只是 SSE 协议事件，不能当成首文字耗时。

状态区分：

| 状态 | 含义 |
| --- | --- |
| 进行中 | 已进入已选客户端的请求处理，响应尚未读完 |
| 完成 | 非流式响应读完，或流已读完且看到了协议完成标记 |
| 失败 | HTTP 错误，或响应内包含协议错误，即使 HTTP 为 200 |
| 响应中断 | 响应数据流报错，或 SSE 结束而没有完成标记 |
| 输出未完成 | Responses 报告 incomplete |
| 已取消 | 请求处理或响应被取消；可能是客户端中断连接 |

“完成”不表示官方客户端文件写读通过，查看活动也不会触发模型请求。模型发现、健康检查、未认证请求、JSON 提取失败和旧 provider 直连路径不计入此面板。客户端模型在进入处理前即被拒绝的情形也可能没有记录；空列表不能单独证明客户端没有发出网络请求。

输入、输出、缓存读取、思考 token 分别显示，缺失为“—”，明确报告的零保留为 0。Anthropic 输入合计包含普通输入、缓存读取和缓存创建；OpenAI 输入采用已含缓存的数值，避免重复相加。增量事件按累计快照合并；不对 token 作文本估算，不推算费用。只解析不超过 64 KiB 的 JSON 响应或单个 SSE data 事件；较大的内容仍原样转发，用量可能未知。超大事件过后仍能识别后续用量与结束事件。

隐私与访问：

- 日志只保存在当前网关的内存，不创建数据库、JSONL 或诊断文件。
- 不保留请求/响应正文、工具参数、HTTP 头、端点地址、上游原始错误、账户和客户端路径。
- `GET /activity/{agent}`、`DELETE /activity/{agent}` 复用本地网关令牌；携带浏览器 Origin 的请求被拒绝。
- 桌面只通过 `agent_hub_activity` 和 `clear_agent_hub_activity` IPC 调用本地服务，不把令牌暴露给页面。
- CLI `ae-switch-cli activity <agent-id>` 读取正在运行的同目录网关；不获取配置 Store 锁，不绑定新端口，不创建替代网关。网关未运行时明确报错。

实现：`src-tauri/src/bridge/activity.rs`；五个 `agent_http` 入口共享旁路观察；`RequestActivityPanel.tsx` 按客户端隔离查询。原始流分片及工具参数不改写，诊断不重试请求或改选模型。
